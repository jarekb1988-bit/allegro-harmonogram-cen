Harmonogram cen Allegro
Prywatna aplikacja sprzedawcy do zarządzania cenami własnych ofert „Kup teraz” na Allegro.pl. Sprzedawca podaje numer oferty, cenę w PLN, dni tygodnia i godzinę zmiany. Aplikacja łączy się z kontem przez OAuth Device Flow, odczytuje bieżącą cenę i o wyznaczonej porze wysyła zmianę przez Allegro REST API. Wynik zapisuje w historii dostępnej w prywatnym panelu.
